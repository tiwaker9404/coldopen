How it works

Three steps, about a minute.

Read their site

A headless browser opens the homepage and reads what’s actually on screen: brand colors, the real font files, the logo, the headline and the numbers they lead with.

Write the script

A model writes six short lines and picks which fact and which proof to show. Code checks every line against written rules and sends it back until it passes.

Render the film

Each scene is a web page on a timeline, filmed frame by frame and encoded with ffmpeg. You get an MP4, a GIF for email and a share page.

It can’t make things up

The model points. The sources speak.

Personalized outreach only works if every word is true. These rules are enforced in code, not just asked for in a prompt.

  • Their facts are quoted, never paraphrasedThe model picks a fact by id. The words on screen are copied from their homepage.
  • Your proof is shown word for wordNumbers come from your profile or résumé, exactly as written.
  • No invented numbersAny number the model writes must exist in their site or your profile, or the line is rejected.
  • No AI slopWord limits per line and 56 banned phrases: “unlock”, “seamless”, “revolutionize”, flattery.
  • Readable by constructionEvery color is solved for WCAG contrast, and text is fitted so nothing overflows.

Crash-proof

Kill the renderer halfway. It finishes anyway.

Every step is checkpointed in Postgres by unkillable, a durable-execution engine built for this. A new worker replays finished work and renders only what’s left. A test kills a real worker on every commit. In its chaos benchmark of 200 refund tickets with workers killed at random:

Install

Free, on your own machine.

You need Node 24 and ffmpeg. For natural copy, add Groq’s free tier or a local model through Ollama; without one, a built-in writer makes plain but always-correct scripts.

git clone https://github.com/tiwaker9404/coldopen && cd coldopen && pnpm install
# draft your profile from your résumé
pnpm coldopen profile resume.pdf me.json --role "Data analyst"
# make a film
pnpm film https://acme.com -p me.json

Teams: docker compose up runs the web app, API, renderer and Postgres. See the README.
