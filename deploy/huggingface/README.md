# coldopen

Paste a company's website and get a 30-second film made for them: their fonts, colors and logo, a line from their own site, and your proof. Start from your résumé, add a job post to answer it, and send a link that tells you when they watched.

This Space runs the hosted demo. The code, docs and a free self-hosted setup are on GitHub: [github.com/tiwaker9404/coldopen](https://github.com/tiwaker9404/coldopen).
